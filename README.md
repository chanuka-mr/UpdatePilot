# UpdatePilot

The Next.js, TypeScript, and Tailwind CSS UI lives in [`apps/web`](apps/web/README.md). The original design reference is in `examples`.

```sh
cd apps/web
npm install
npm run dev
```

The read-only Windows scanner lives in [`apps/windows-agent`](apps/windows-agent/README.md). PostgreSQL setup and scan import commands are in [`apps/api`](apps/api/README.md).
